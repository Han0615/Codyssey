## 1. 개요

화성 기지에서 생존에 필요한 물자 계산을 위해 Python과 PyQt6 라이브러리를 활용하여 아이폰 계산기 UI와 유사한 계산기를 구현하였다. 4칙 연산(+, -, ×, ÷)과 AC, +/-, % 기능을 포함하였다.

---

## 2. 사용 모듈 및 선택 이유

| 모듈 | 종류 | 사용 이유 |
|------|------|-----------|
| `sys` | Python 표준 라이브러리 | `QApplication` 실행 인자 전달 및 `sys.exit()`으로 프로그램을 안전하게 종료하기 위해 사용하였다. |
| `PyQt6.QtCore.Qt` | PyQt6 (허용된 라이브러리) | 디스플레이 텍스트 정렬 방향을 지정하기 위해 사용하였다. |
| `PyQt6.QtWidgets` | PyQt6 (허용된 라이브러리) | UI 구성에 필요한 `QApplication`, `QWidget`, `QLabel`, `QPushButton`, `QVBoxLayout`, `QGridLayout`을 가져오기 위해 사용하였다. |

---

## 3. 주요 코드 설명

### 3.1 `__init__()` — UI 초기화

창 크기, 배경색, 디스플레이, 버튼 레이아웃을 구성한다. 버튼 배치는 2차원 리스트로 정의하여 `for`문으로 순회하며 그리드에 추가한다. 마지막 행의 `0` 버튼만 2칸 너비로 별도 처리하여 아이폰 계산기와 동일한 배치를 구현하였다.

### 3.2 `_make_btn()` — 버튼 생성

버튼 텍스트를 받아 색상과 스타일을 적용한 버튼 객체를 반환한다. 연산자 버튼은 주황색(`#FF9500`), 기능 버튼(AC, +/-, %)은 회색(`#A5A5A5`), 숫자 버튼은 어두운 회색(`#333333`)으로 구분하였다. 버튼 클릭 이벤트는 `lambda`로 `on_click()`에 연결하였다.

### 3.3 `on_click()` — 버튼 클릭 처리

버튼 종류에 따라 동작을 분기한다. 숫자와 연산자는 `self.expression`에 누적하고, `=`를 누르면 `eval()`로 계산한다. `÷`와 `×`는 Python이 인식하지 못하므로 `replace()`로 `/`와 `*`로 변환 후 계산한다. 계산 오류 발생 시 `'오류'`를 출력하고 수식을 초기화한다.

## 4. 버튼 구성

| 행 | 버튼 | 색상 |
|----|------|------|
| 1행 | AC, +/-, %, ÷ | 회색 / 주황 |
| 2행 | 7, 8, 9, × | 어두운 회색 / 주황 |
| 3행 | 4, 5, 6, - | 어두운 회색 / 주황 |
| 4행 | 1, 2, 3, + | 어두운 회색 / 주황 |
| 5행 | 0(2칸), ., = | 어두운 회색 / 주황 |
